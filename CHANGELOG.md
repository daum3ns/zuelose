# Changelog

## [Unreleased]

### Added

- Radio station search, favourites, and favourite categories.
- Podcast search, subscriptions, episode browsing, and resume playback.
- Multiple colour themes and keyboard-driven pane navigation.
- `make install`, version reporting, automated CI, vulnerability scanning, and tag-based releases.
- Changelog-driven GitHub Release notes.

### Changed

- Expanded and made the help overlay scrollable.
- Moved playback hints into the now-playing pane and notifications into the header.

### Fixed

- Radio playback now starts correctly after pausing a podcast.

### Security

- Updated the Go toolchain and `golang.org/x/net` to versions addressing current vulnerability advisories.
